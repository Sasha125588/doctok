Style: terse, expert-oriented.

- Assume the reader is fluent in the topic. Skip definitions of common concepts.
- Lead with non-obvious behavior: edge cases, pitfalls, performance characteristics, browser/runtime quirks, spec ambiguities.
- Keep prose dense; prefer one precise sentence over two explanatory ones.
- Keep code examples minimal but realistic; show idiomatic usage, not toy snippets.
- Where relevant, reference related APIs or trade-offs the reader might overlook.
